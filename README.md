## About

DevOps engineer focused on containerized deployments and Linux-based infrastructure. I build multi-stage Docker images, wire services together with Docker Compose and Nginx, manage configuration with Ansible, and deploy on AWS. Backend development in Node.js and NestJS is my secondary strength — it helps me debug what runs inside the containers, not just how it ships.
